# Pack contents

This pack contains Claude Code operating files for the radar SAR thesis project.

Core:
- `CLAUDE.md`: short always-loaded project instructions.
- `CLAUDE.local.example.md`: optional personal local preferences.
- `.gitignore`: protects raw data, secrets, and local Claude settings.
- `.claude/settings.json`: conservative permissions template.
